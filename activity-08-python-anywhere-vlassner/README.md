# Introduction 

[Python Anywhere](https://www.pythonanywhere.com/) is a service that allows users to run Python web apps in the cloud, using different framework flavors, including Flask. 

# Instructions

After you create your account and sign-in on Python Anywhere, select the **Open Web tab** and then **Add a new web app**.  Just follow the instructions of the wizard and create a sample web app.  After testing and making sure your sample web app is running, edit the app's folder to customize it. 

Python Anywhere supports virtual environments, so you can add your favorite libraries such as Flask-Login, Flask-WFT, etc. Python Anywhere also has an API to facilitate integration. More info about their API can be found [here](https://help.pythonanywhere.com/pages/IntegratingWithPythonAnywhere/).
