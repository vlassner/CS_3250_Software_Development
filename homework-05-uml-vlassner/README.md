# Instructions
# Victoria Lassner

Create a class diagram in UML (save it in **uml.wsd**) to meet the following requirements: 

* a flight is identified by the airline code ("UA", "Delta", "AA", etc.) and a number; 
* an aircraft has a (textual) prefix, a number, a manufacturer, a model, and a capacity (in number of passegers it can safely carry); 
* your model should allow navigation from a flight object to the aircraft (object) that is operating the flight; 
* an airport is identified by its IATA number, city, state, and country location; 
* a flight connects to different airports at different dates and times; 
* your model should allow navigation from connection (object) to the flight and airport objects. 

# Rubric 

```
-1 for each class/association missing
-1 for each 2 attributes missing in a class/association
```
